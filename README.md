## 🔬 Master's Research Focus

* 🎓 **Master of Science in Computer Science** — National Taipei University of Technology
* 📜 **Thesis**: *A Self-Correction Mechanism for LLM Agents in API Tasks Using Case-Based Learning and Dynamic Plan Repair*
* 💡 **Key Specializations**:
  * **LLM Agents & API Automation**: Multi-step agent architectures executing complex workflows on environments like AppWorld.
  * **RAG & Case-Based Reasoning**: Implemented **Atomic Experience Reuse** to retrieve fine-grained strategy patterns for agent planning and recovery.
  * **Self-Correction & Dynamic Plan Repair**: Developed local plan repair mechanisms (insert, replace, delete) to recover from step failures without full replanning.
